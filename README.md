# dnbls.com

Personal site + blog.

## Tech

- Next.js (App Router), React, TypeScript
- MDX (`@next/mdx`, `remark-gfm`, `rehype-*`)
- Tailwind CSS v4
- UI: shadcn/ui (+ Base UI), `motion`
- Lint/format: Biome
- Package manager: pnpm

## Getting started

```bash
pnpm install
pnpm dev
```

Other useful commands:

```bash
pnpm build
pnpm start
pnpm lint
pnpm format
```
